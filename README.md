# 🍎 NutriApp Pro
Meu primeiro aplicativo de nutrição desenvolvido com **React Native** e **Expo**.

## ✨ Destaques do Projeto:
- **Painel de Controle:** Gráfico de calorias diárias, água e proteínas.
- **Monetização:** Configuração real de **Google AdMob** (Banner Adaptativo).
- **Layout Moderno:** Interface limpa e intuitiva para o usuário.
